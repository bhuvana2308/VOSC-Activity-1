# Tic-Tac-Toe Game

## About the Project

This is a simple two-player Tic-Tac-Toe game developed using HTML, CSS, and JavaScript.

The game allows two players to take turns placing X and O on a 3 × 3 board.

## Features

* Two-player gameplay
* Player turn indication
* Winner detection
* Draw detection
* Restart game button
* Simple and responsive interface

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Start playing Tic-Tac-Toe.

## How to Play

1. Player X starts the game.
2. Players take turns clicking an empty cell.
3. The first player to get three matching symbols in a row, column, or diagonal wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Click the **Restart Game** button to play again.
